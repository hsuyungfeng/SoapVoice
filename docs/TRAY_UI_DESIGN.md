## 控制按鈕說明

### 主控制區

| 按鈕 | 快捷鍵 | 功能 |
|------|--------|------|
| 🎤 開始錄音 | Ctrl+R | 開始錄製音訊 |
| ⏹ 停止錄音 | Ctrl+T | 停止錄音並開始處理 |
| 📸 擷取畫面 | Ctrl+S | 擷取螢幕進行OCR識別 |

### 結果操作區

| 按鈕 | 功能 |
|------|------|
| [複製] | 複製 SOAP 到剪貼簿 |
| [複製全部] | 複製病患資訊+逐字稿+SOAP |
| [貼上] | 貼上到目前作用中視窗 |

### 儲存區

| 按鈕 | 功能 |
|------|------|
| 💾 儲存本地 | 保存 WAV + JSON 到本地 |
| ☁️ 雲端匯出 | 匯出到 Google Drive/SMB |
| 🗑️ 刪除 | 刪除目前記錄 |

## 實作技術

```python
# System Tray 實作
import pystray
from PIL import Image

# 創建系統匣
icon = pystray.Icon(
    "SoapVoice",
    image=create_icon(),
    menu=create_menu(),
    title="SoapVoice"
)

# 選單項目
def create_menu():
    return pystray.Menu(
        pystray.MenuItem("📸 擷取病患資訊", on_capture),
        pystray.MenuItem("🎤 開始錄音", on_start_recording),
        pystray.MenuItem("⏹ 停止錄音", on_stop_recording),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem("📋 複製 SOAP", on_copy_soap),
        pystray.MenuItem("📋 複製全部", on_copy_all),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem("💾 開啟記錄資料夾", on_open_folder),
        pystray.MenuItem("☁️ 雲端匯出", on_cloud_export),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem("⚙️ 設定", on_settings),
        pystray.MenuItem("🚪 結束程式", on_exit),
    )
```
