# SoapVoice 新功能規格書

## Phase 8: 門診語音錄製系統

### 功能概述

建立一個常駐系統匣的門診語音錄製系統，自動擷取病患資訊並生成 SOAP 病歷。

### 功能清單

#### 1. 常駐工具列 (System Tray)
- **說明**: 應用程式常駐於 Windows 系統匣
- **功能**:
  - 點擊圖示開啟主選單
  - 右鍵選單：開始錄音、擷取螢幕、設定、結束
  - 顯示錄音狀態（錄音中/待機中）
  - 開機自動啟動（可選）

#### 2. 病患資訊擷取 (Screenshot + OCR)
- **說明**: 擷取螢幕畫面並識別病患資料
- **流程**:
  1. 使用者按下快捷鍵或點擊擷取
  2. 擷取主螢幕畫面
  3. 使用 EasyOCR 識別以下欄位：
     - 病患姓名 (patient_name)
     - 出生日期 (birthday)
     - 身份證號 (id_number)
     - 病歷號 (medical_record_number)
     - 時間戳 (timestamp)
     - 醫師姓名 (doctor_name)
  4. 顯示識別結果供確認

#### 3. 語音錄製 + LLM SOAP 生成
- **說明**: 錄製醫師語音並自動生成 SOAP 病歷
- **流程**:
  1. 開始錄音（使用 PyAudio）
  2. 錄音結束後自動轉文字（ASR）
  3. 提取病患資訊（從步驟 2）
  4. 呼叫 LLM 生成 SOAP 病歷
  5. 顯示逐字稿（transcript）

#### 4. 結果浮動視窗（右側）
- **說明**: 顯示完整錄製結果的浮動視窗
- **功能**:
  - 顯示病患資訊（可編輯）
  - 顯示逐字稿
  - 顯示 SOAP 病歷
  - 一鍵複製 SOAP 到剪貼簿
  - 關閉按鈕（儲存後關閉）

#### 5. HIS 剪貼簿整合
- **說明**: 複製 SOAP 到醫院資訊系統
- **功能**:
  - 一鍵複製 SOAP 文字
  - 自動去除格式（純文字）
  - 顯示複製成功訊息

#### 6. 本地儲存 + 雲端匯出
- **說明**: 儲存錄音和病歷
- **本地儲存**:
  - 音訊檔：WAV 格式
  - 文字檔：JSON 格式（含病患資訊、逐字稿、SOAP）
  - 儲存位置：`data/recordings/`
- **雲端匯出**:
  - 支援 Google Drive API
  - 支援 SMB/網路芳鄰
  - 匯出格式：ZIP（含 WAV + JSON）

### 技術架構

```
┌─────────────────────────────────────────────────────────────┐
│                    System Tray (常駐)                       │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │ 擷取螢幕    │    │ 開始錄音    │    │ 設定        │      │
│  │ (OCR)      │    │ (ASR+LLM)   │    │            │      │
│  └─────────────┘    └─────────────┘    └─────────────┘      │
├─────────────────────────────────────────────────────────────┤
│                    Results Window (浮動視窗)                │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 病患資訊 │ 逐字稿 │ SOAP │ [複製SOAP] [儲存] [匯出]  │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                    Local Storage                            │
│  └── data/recordings/                                       │
│      ├── 2026-04-09_143022_病患姓名.wav                    │
│      └── 2026-04-09_143022_病患姓名.json                   │
└─────────────────────────────────────────────────────────────┘
```

### UI 設計

#### 系統匣圖示
- 待機中：灰色 microphone 圖示
- 錄音中：紅色閃爍 microphone 圖示

#### 浮動視窗
- 位置：螢幕右側固定
- 大小：400x600 像素（可調整）
- 功能：顯示所有結果，一鍵複製

### 資料格式

```json
{
  "id": "2026-04-09_143022",
  "timestamp": "2026-04-09T14:30:22",
  "patient": {
    "name": "王小明",
    "birthday": "1980-01-15",
    "id_number": "A123456789",
    "medical_record_number": "MRN123456"
  },
  "doctor": "林醫師",
  "transcript": "病人主訴胸悶兩天...",
  "soap": {
    "subjective": "...",
    "objective": "...",
    "assessment": "...",
    "plan": "..."
  },
  "audio_file": "2026-04-09_143022.wav"
}
```

### 使用流程

```
1. 系統啟動 → 最小化到系統匣
2. 點擊「擷取螢幕」 → 擷取畫面 → OCR識別病患資訊
3. 點擊「開始錄音」 → 錄製語音 → 自動生成SOAP
4. 結果視窗彈出 → 確認/編輯 → 複製到HIS
5. 點擊「儲存」 → 本地存檔 → 可選「匯出雲端」
```

### 實作優先順序

1. **Phase 8.1**: 系統匣常駐 + 基本選單
2. **Phase 8.2**: 螢幕擷取 + OCR 病患資訊
3. **Phase 8.3**: 語音錄製 + ASR
4. **Phase 8.4**: LLM SOAP 生成
5. **Phase 8.5**: 浮動視窗 + 複製功能
6. **Phase 8.6**: 本地儲存 + 雲端匯出
