# 🎤 SoapVoice GUI 使用說明

## 📋 功能概述

SoapVoice GUI 是一個醫療語音轉 SOAP 病歷的桌面應用程式，專為診所醫師設計，提供快速、直觀的語音錄製與病歷生成功能。

## 🚀 快速開始

### 安裝必要套件
```bash
uv sync
uv add pyperclip ttkbootstrap pyaudio
```

### 啟動應用程式
```bash
# 方法一：使用啟動腳本
python run_gui.py

# 方法二：直接執行
uv run python -m src.gui.desktop_app
```

## 🖥️ 介面說明

### 主視窗 (300x120 像素)
```
┌─────────────────────────────────────┐
│ 🎤 SoapVoice                ✅ 準備就緒 │
├─────────────────────────────────────┤
│ [🎤 開始錄音] [⏹ 停止] [⚡ 處理] [🧪 測試] │
│                   ●                  │
└─────────────────────────────────────┘
```

### 按鈕功能
| 按鈕 | 顏色 | 功能說明 |
|------|------|----------|
| 🎤 開始錄音 | 🔴 紅色 | 開始錄製語音對話 |
| ⏹ 停止 | ⚫ 灰色 | 停止錄音 |
| ⚡ 處理 | 🟠 橙色 | 處理錄音生成 SOAP 病歷 |
| 🧪 測試 | 🟣 紫色 | 使用測試音檔快速測試 |

### 狀態指示燈
- **🔴 紅色閃爍:** 錄音中
- **🟠 橙色:** 處理中
- **🟢 綠色:** 準備就緒/完成

## 📝 使用流程

### 1. 語音錄製流程
```
開始錄音 → 停止錄音 → 處理 → 查看結果
    ↓         ↓         ↓         ↓
   🔴        ⚫        🟠        🟢
```

### 2. 快速測試流程
```
點擊「🧪 測試」按鈕 → 自動使用測試音檔 → 查看結果
```

## 🎯 功能特色

### ✅ 已完成功能
1. **扁平化設計** - 300x120 橫向長條形視窗
2. **彩色視覺提示** - 不同狀態使用不同顏色
3. **麥克風圖示** - 直觀的錄音按鈕

### 📁 測試音檔

- `chest_pain.wav` - 胸痛
- `hypertension.wav` - 高血壓
- `diabetes.wav` - 糖尿病
- `respiratory.wav` - 呼吸道問題
- `wound_care.wav` - 傷口護理
- `drug_order.wav` - 藥物醫囑
- `surgery_record.wav` - 手術記錄
- `doctor_patient.wav` - 醫病對話

## 🐛 疑難排解

### 常見問題

#### Q1: 無法啟動 GUI
```
錯誤: ModuleNotFoundError: No module named 'pyperclip'
```
**解決方案:**
```bash
uv add pyperclip ttkbootstrap pyaudio
```

#### Q2: 無法錄音
```
錯誤: ALSA lib pcm_dmix.c:1000:(snd_pcm_dmix_open) unable to open slave
```
**解決方案:**
- 檢查麥克風權限
- 確保音訊裝置正常
- Linux 系統可能需要安裝 `portaudio`

#### Q3: 後端 API 無法連接
```
狀態: 系統初始化中...
```
**解決方案:**
- 確保 Ollama 服務正在運行
- 檢查端口 8080 是否被佔用
- 重啟應用程式

### 錯誤代碼
| 錯誤訊息 | 可能原因 | 解決方案 |
|----------|----------|----------|
| `❌ 無音檔` | 未錄製音檔 | 先點擊「開始錄音」 |
| `❌ 轉錄失敗` | ASR 服務異常 | 檢查後端 API |
| `❌ 找不到測試音檔` | 測試檔案遺失 | 重新下載專案 |
