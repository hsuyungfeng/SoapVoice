建立 PyInstaller spec 檔案與打包配置：

1. 安裝 PyInstaller（若尚未安裝）：
   - 執行 `uv add --group dev pyinstaller` 或 `pip install pyinstaller`。
   - 確認 pyproject.toml 的 `[project.optional-dependencies]` 或 `[dependency-groups]` 包含 `pyinstaller`（可選，但建議加入 dev 群組）。

2. 產生 spec 檔案：
   - 使用 `pyi-makespec --onefile --name SoapVoice src/gui/desktop_app.py` 產生基礎 spec。
   - 將產生的 `SoapVoice.spec` 更名為 `soapvoice.spec` 並置於專案根目錄。

3. 編輯 `soapvoice.spec`，根據 RESEARCH.md 的 Pattern 1 進行配置：
   - 在 `Analysis` 的 `datas` 中加入 `models/` 與 `data/` 目錄（遞迴包含）。
   - 在 `hiddenimports` 中加入所有可能動態導入的模組：`llama_cpp`, `llama_cpp.llama`, `llama_cpp._internals`, `faster_whisper`, `ctranslate2`, `ttkbootstrap`, `tkinter`, `PIL`, `pyaudio`, `pyperclip`, `mss`, `sentence_transformers`, `chromadb`。
