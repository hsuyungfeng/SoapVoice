  <name>Task 1: 建立 Inno Setup 安裝腳本</name>
  <files>installer/soapvoice.iss</files>
  <action>
建立 Inno Setup 安裝腳本：

1. 建立 `installer/` 目錄（若不存在）。
2. 在 `installer/soapvoice.iss` 中撰寫安裝腳本，參考 RESEARCH.md 的 Pattern 3 並依據專案需求調整：
   - `[Setup]` 區段：定義 `AppName=SoapVoice`、`AppVersion=0.8.0`、`DefaultDirName={pf}\\SoapVoice`、`DefaultGroupName=SoapVoice`、`UninstallDisplayIcon={app}\\SoapVoice.exe`、`Compression=lzma2/ultra64`、`SolidCompression=yes`、`OutputDir=installer\\`、`PrivilegesRequired=admin`。
   - `[Files]` 區段：包含 `dist\\SoapVoice.exe` 作為主要執行檔（`Flags: ignoreversion`）。若模型與資料檔案已嵌入 EXE，則無需額外複製；否則需包含 `models\\` 與 `data\\` 目錄。
   - `[Icons]` 區段：建立開始功能表捷徑 `{group}\\SoapVoice` 與解除安裝捷徑 `{group}\\Uninstall SoapVoice`，以及桌面捷徑 `{commondesktop}\\SoapVoice`。
   - `[Run]` 區段：安裝後可選擇啟動應用程式（`Flags: postinstall nowait skipifsilent`）。
   - `[UninstallDelete]` 區段：刪除使用者資料目錄（`{localappdata}\\SoapVoice`），避免殘留檔案。

3. 加入無訊息安裝支援：確保腳本兼容 `/SILENT`、`/VERYSILENT`、`/DIR=` 等標準參數（Inno Setup 預設支援）。

4. 可選：加入授權檔案 `license.txt` 與橫幅圖片 `banner.bmp`。

注意：腳本中使用雙反斜線 `\\` 表示 Windows 路徑，並確保路徑與專案結構一致。
