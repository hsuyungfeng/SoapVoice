**2. 建立 LAN IP 白名單 middleware（在 src/main.py 中整合）：**
- 在 main.py 的 FastAPI 初始化後，add middleware：
  ```python
  from fastapi.middleware import Middleware
  from starlette.middleware.base import BaseHTTPMiddleware
  
  class LANWhitelistMiddleware(BaseHTTPMiddleware):
      """
      LAN IP 白名單驗證 middleware
      允許的 IP 範圍：
      - 192.168.0.0 - 192.168.255.255
      - 10.0.0.0 - 10.255.255.255
      - 127.0.0.1（本機開發）
      """
      async def dispatch(self, request: Request, call_next):
          client_ip = request.client.host
          # 檢查 client_ip 是否在允許清單內
          if not is_lan_ip(client_ip):
              return JSONResponse(
                  status_code=403,
                  content={"error": f"IP {client_ip} not in LAN whitelist"}
              )
          response = await call_next(request)
          return response
  
  # 在 main.py app = FastAPI(...) 後新增
  app.add_middleware(LANWhitelistMiddleware)
  ```
- 編寫 `is_lan_ip(ip: str) -> bool` 輔助函式，檢查 IP 是否屬於 192.168/10.0/127.0 段
- 所有 /api/v1/lan/* 和 /api/v1/health 端點均受此 middleware 保護

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN Network Edge | 來自 LAN IP 的 HTTP 請求可直接呼叫 /api/v1/lan/* |
| Untrusted Audio/Screenshot | 客戶端上傳的 WAV、JPG 未必真正符合格式 |
| Process Pool (LLM) | 推理 process 隔離但與主線程共享記憶體 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Spoofing | LAN IP whitelist | mitigate | Middleware 驗證 request.client.host，拒絕非 192.168/10.0/127.0 IP |
| T-11-02 | Tampering | Multipart file upload | mitigate | 驗證副檔名與 MIME type，限制檔案大小（WAV ≤ 100MB，JPG ≤ 10MB），使用 librosa 校驗 WAV 格式 |
| T-11-03 | Repudiation | Session tracking | mitigate | 所有 session_id 寫入 SQLite audit_log，含時間戳與客戶端 IP（middleware 記錄） |
| T-11-04 | Information Disclosure | Opus compression | accept | Opus codec 非加密，僅減少頻寬；若需保密，在 HTTPS/TLS 層加密傳輸（Phase 12+ 部署時啟用） |
| T-11-05 | Denial of Service | Unbounded multipart | mitigate | FastAPI 預設限制 100MB，WAV ≤ 100MB check，截圖 ≤ 10MB check；無需額外限速 |
| T-11-06 | Elevation of Privilege | LLM process exec | mitigate | LLM 推理 process 以主應用相同使用者運行，無特殊權限提升；process pool 受 asyncio.Semaphore(1) 限制（下個 phase） |

</threat_model>
