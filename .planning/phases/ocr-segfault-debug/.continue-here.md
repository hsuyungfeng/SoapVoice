<current_state>
已修復 SoapVoice GUI 啟動時的段錯誤（記憶體區段錯誤）。問題根源在於：
1. OCR 解析器嘗試使用 Ollama Vision 模型，而系統配置為 llama.cpp CPU 離線模式（無 Ollama 服務）
2. 全螢幕截圖（3840x2160 RGBA）導致記憶體壓力與庫衝突
3. 背景執行緒中直接更新 tkinter UI 引發執行緒安全問題

修復方案：
- 當 `USE_LLAMA_CPP=true` 時，OCR 解析器自動跳過 Ollama Vision 與 EasyOCR，僅使用 Tesseract 主力引擎
- 添加影像縮小機制（>1920px 縮小 50%），減少記憶體使用與處理負擔
- 使用 `root.after()` 進行執行緒安全的 UI 更新
- 增加截圖與 numpy 陣列的安全性檢查

GUI 啟動測試穩定，未出現段錯誤。下一步需驗證完整功能流程與 Windows 離線打包。
</current_state>
