建立 `static/js/dashboard.js`，實現即時指標推送與歷史圖表邏輯。

**核心模組結構：**

1. **全域狀態物件** — `dashboardState`
   - `connected: boolean` — SSE 連線狀態
   - `lastMetrics: Object` — 最後一筆收到的指標快照
   - `metricsHistory: Array` — 圖表用歷史指標陣列
   - `chart: Chart` — Chart.js 圖表實例
   - `currentGranularity: string` — 目前選擇的粒度（"hour" / "day"）

2. **SSE 連線管理** — `initSSE()`
   - 建立 `EventSource('/api/v1/metrics/stream')`
   - onopen：設定 `dashboardState.connected = true`，更新連線指示燈為綠色
   - onmessage：解析 JSON payload，更新 `dashboardState.lastMetrics`，調用 `updateMetricsUI()`
   - onerror：設定 `dashboardState.connected = false`，更新連線指示燈為紅色，記 console.warn
   - 無需手動重連（瀏覽器 EventSource 原生自動重連機制，3 秒失敗後指數退避）

3. **UI 更新函式** — `updateMetricsUI()`
   - 從 `dashboardState.lastMetrics` 讀取 gpu_percent、vram_mb、gpu_memory_total_mb、queue_length
   - 更新 HTML 元素：
     - `#gpuPercent` 文字 = `${gpu_percent.toFixed(1)}%`
     - `#vramUsage` 文字 = `${vram_mb.toFixed(0)} MB / ${gpu_memory_total_mb.toFixed(0)} MB`
     - `#queueLength` 文字 = `${queue_length}`
   - 更新 `#lastUpdate` 時間戳（相對時間，e.g., "3 秒前"）
   - 可選：若 gpu_percent > 90 時，卡片加紅色邊框警告

4. **歷史圖表初始化** — `initChart()`
   - 建立 Chart.js 線圖，X 軸時間，Y 軸 GPU%
   - 初始載入歷史資料：`GET /api/v1/metrics/history?granularity=hour&limit=100`
   - 解析回傳陣列，萃取 timestamp + gpu_percent，轉換時間格式（HH:MM 或 MM/DD HH:MM）
   - Chart.js 設定：
     ```javascript
     const ctx = document.getElementById('metricsChart').getContext('2d');
     dashboardState.chart = new Chart(ctx, {
       type: 'line',
       data: {
         labels: [...timestamps...],
         datasets: [{
           label: 'GPU 使用率 (%)',
           data: [...gpu_percents...],
           borderColor: 'rgb(75, 192, 192)',
           tension: 0.1
         }]
       },
       options: { responsive: true, scales: { y: { min: 0, max: 100 } } }
     });
     ```

5. **粒度切換邏輯** — `onGranularityChange()`
   - 監聽 radio button change 事件
   - 更新 `dashboardState.currentGranularity`
   - 呼叫 `loadHistoryAndUpdate()`

6. **歷史資料載入** — `loadHistoryAndUpdate()`
   - `fetch('/api/v1/metrics/history?granularity=' + dashboardState.currentGranularity + '&limit=100')`
   - 解析回傳 JSON，更新 `dashboardState.metricsHistory`
   - 更新圖表資料：`dashboardState.chart.data.labels = newLabels; dashboardState.chart.data.datasets[0].data = newValues; dashboardState.chart.update();`

7. **患者統計更新** — `loadConsultationStats()`
   - 呼叫兩次 GET /api/v1/records/search：
     - 本日：`date_from=today, date_to=today, page_size=1` 取 total
     - 本月：`date_from=month_start, date_to=month_end, page_size=1` 取 total
   - 更新 HTML：`#todayConsults.innerText = todayTotal; #monthlyConsults.innerText = monthlyTotal;`
   - 可選：如果查詢失敗，顯示 "-- 筆" 或載入中圖示

8. **初始化入口** — `initDashboard()`
   - 文件載入完成時執行 (DOMContentLoaded 事件)
   - 呼叫 initSSE()
   - 呼叫 initChart()
   - 呼叫 loadConsultationStats()
   - 設定 radio button change 事件監聽

**錯誤處理：**
- fetch 失敗時 console.warn，UI 顯示 "-- 筆" 或 "連線失敗"
- 指標解析失敗時 console.warn，保留上次有效值

**時間相關工具函式：**
- `formatRelativeTime(timestamp)` — 將 Unix timestamp 轉換為相對時間字串（"剛剛"、"3 秒前"、"2 分鐘前"）
- `formatTimeForChart(timestamp, granularity)` — 根據粒度格式化時間標籤（小時：HH:MM，日：MM/DD）

範例實作 (pseudo-code)：
```javascript
const dashboardState = { connected: false, lastMetrics: null, chart: null, currentGranularity: 'hour' };

function initSSE() {
  const es = new EventSource('/api/v1/metrics/stream');
  es.onopen = () => { dashboardState.connected = true; updateConnectionUI(true); };
  es.onmessage = (event) => {
    dashboardState.lastMetrics = JSON.parse(event.data);
    updateMetricsUI();
  };
  es.onerror = () => { dashboardState.connected = false; updateConnectionUI(false); };
}

function updateMetricsUI() {
  const m = dashboardState.lastMetrics;
  document.getElementById('gpuPercent').innerText = `${m.gpu_percent.toFixed(1)}%`;
  document.getElementById('vramUsage').innerText = `${m.vram_mb.toFixed(0)} MB / ${m.gpu_memory_total_mb.toFixed(0)} MB`;
  document.getElementById('queueLength').innerText = `${m.queue_length}`;
  document.getElementById('lastUpdate').innerText = `上次更新：${formatRelativeTime(m.timestamp)}`;
}

function initChart() {
  fetch('/api/v1/metrics/history?granularity=hour&limit=100')
    .then(r => r.json())
    .then(data => {
      dashboardState.metricsHistory = data.metrics;
      const labels = data.metrics.map(m => formatTimeForChart(m.timestamp, 'hour'));
      const values = data.metrics.map(m => m.gpu_percent);
      dashboardState.chart = new Chart(document.getElementById('metricsChart').getContext('2d'), {
        type: 'line',
        data: { labels, datasets: [{ label: 'GPU %', data: values, borderColor: 'rgb(75, 192, 192)' }] },
        options: { responsive: true, scales: { y: { min: 0, max: 100 } } }
      });
    });
}

function loadConsultationStats() {
  const today = new Date().toISOString().split('T')[0];
  fetch(`/api/v1/records/search?date_from=${today}&date_to=${today}&page_size=1`)
    .then(r => r.json())
    .then(data => { document.getElementById('todayConsults').innerText = data.total || 0; });
  
  const month = new Date();
  const start = new Date(month.getFullYear(), month.getMonth(), 1).toISOString().split('T')[0];
  const end = new Date(month.getFullYear(), month.getMonth() + 1, 0).toISOString().split('T')[0];
  fetch(`/api/v1/records/search?date_from=${start}&date_to=${end}&page_size=1`)
    .then(r => r.json())
    .then(data => { document.getElementById('monthlyConsults').innerText = data.total || 0; });
}

document.addEventListener('DOMContentLoaded', () => {
  initSSE();
  initChart();
  loadConsultationStats();
  document.querySelectorAll('input[name="granularity"]').forEach(radio => {
    radio.addEventListener('change', (e) => {
      dashboardState.currentGranularity = e.target.value;
      loadHistoryAndUpdate();
    });
  });
});
```
